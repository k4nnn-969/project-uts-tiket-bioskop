# Login Demo

Login hanya digunakan untuk demonstrasi tampilan. Isi email dan kata sandi apa pun; keduanya harus terisi, tetapi tidak diperiksa ke database. Status login disimpan di `localStorage` browser dan dapat dihapus melalui tombol **Keluar**.

Login demo ini bukan autentikasi yang aman dan tidak boleh digunakan untuk produksi.
